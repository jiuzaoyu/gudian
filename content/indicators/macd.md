## 人话解释

想象两个人在跑步：

- **快线（DIF）** = 跑得快的人（代表短期趋势）
- **慢线（DEA）** = 跑得慢的人（代表长期趋势）

当快的人从后面追上慢的人 → **金叉** → 常被解读为可能转强  
当快的人从前面掉到慢的人后面 → **死叉** → 常被解读为可能转弱  

**MACD 柱**的高低 = 两人之间的距离，距离越大，趋势动能往往越强。

## 计算公式（了解即可）

```
DIF = 12日EMA - 26日EMA
DEA = DIF 的 9日EMA
MACD柱 = (DIF - DEA) × 2
```

## 常见误区

| 误区 | 正解 |
|------|------|
| ❌ 金叉就一定买 | 震荡市里金叉可能是假信号，需结合整体趋势 |
| ❌ MACD 适合超短线 | 它是趋势类指标，反应偏慢，更适合中线参考 |
| ❌ 只看柱子颜色 | 应同时看 DIF、DEA 的位置和股价结构 |

## 什么时候有用 / 没用

| 适用场景 | 不适用场景 |
|----------|------------|
| 趋势较明显的上涨或下跌 | 横盘震荡、频繁金叉死叉 |
| 辅助判断中期方向 | 追求精确到分钟的买卖点 |
