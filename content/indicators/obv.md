## 人话解释

**OBV**（On-Balance Volume，常译 **能量潮** 或 **累积成交量线**）把每天的成交量，按股价是涨还是跌，**一路加加减减**，画成一条曲线。

核心逻辑很简单：

| 当天收盘 vs 昨天 | OBV 怎么变 |
|------------------|------------|
| **涨了** | 把当天成交量 **加** 上去 |
| **跌了** | 把当天成交量 **减** 下去 |
| **平盘** | 一般 **不变**（各软件细节可能略有差异） |

可以把它想成：**涨的时候算「买盘推上来的量」，跌的时候算「卖盘压下去的量」**，长期累加后，看资金是跟着价往上走，还是在悄悄撤离。

### 软件上常见怎么看？

- **OBV 与股价同向创新高**：上涨有量配合，趋势往往更「踏实」
- **OBV 与股价同向创新低**：下跌有量配合，跌势可能还在延续
- **股价创新高，OBV 没跟上（顶背离）**：价在涨，但累积量能走弱，需警惕上涨动力不足（进阶用法，不能机械套用）
- **股价创新低，OBV 没跟上（底背离）**：价在跌，但卖压可能在减弱，需结合其他信号确认

OBV 看的是**量价配合**，不是单独预测明天涨跌。

### 和换手率、量比怎么区分？

| 指标 | 看什么 | 特点 |
|------|--------|------|
| **OBV** | 成交量随涨跌方向的**累积** | 一条曲线，看趋势与量价是否一致 |
| **换手率** | 成交量占流通股本的比例 | 百分比，看交易活跃程度 |
| **量比** | 当前量 vs 近期平均量 | 比值，看此刻放量还是缩量 |

## 计算公式（了解即可）

从某一基准日起，逐日累加：

```
若 今日收盘 > 昨日收盘：OBV = 昨日 OBV + 今日成交量
若 今日收盘 < 昨日收盘：OBV = 昨日 OBV − 今日成交量
若 今日收盘 = 昨日收盘：OBV = 昨日 OBV（通常不变）
```

OBV 的**绝对数值**大小没有标准意义（不同股票差很多），重点看**走势方向**以及和**股价**是否一致。

## 常见误区

| 误区 | 正解 |
|------|------|
| ❌ OBV 高就是好事 | 要看股价方向；下跌中 OBV 也可能一路走低 |
| ❌ 背离一定反转 | 背离只是提示动能可能变化，需结合趋势、位置、其他指标 |
| ❌ OBV 可以单独买卖 | 它是量价辅助线，不能替代基本面和完整技术分析 |
| ❌ 和换手率是一回事 | 换手率看「换手的比例」，OBV 看「量随涨跌的累积方向」 |
| ❌ 绝对值能横比不同股票 | 应看各自 OBV 曲线的相对走势，不要比具体数字 |

## 什么时候有用 / 没用

| 适用场景 | 不适用场景 |
|----------|------------|
| 判断上涨/下跌有没有成交量配合 | 代替研究公司业绩、估值 |
| 与股价对照，观察量价是否一致、是否背离 | 横盘、量能极小时（信号容易失真） |
| 理解「量在价先」类分析思路 | 追求精确到分钟的买卖点 |
