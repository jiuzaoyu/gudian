## 人话解释

**做多** = 你看涨，于是**先买后卖**：

1. 在较低价位**买入**股票（或基金等）
2. 等价格上涨后**卖出**
3. 赚取价差（还要扣除手续费、印花税等）

可以记成：**「多」= 多头 = 站在「涨」这一边**。

在 A 股市场，普通投资者开户后默认就是**只能做多**——先买进持仓，不能随意「先卖后买」去赌下跌（那是 **[做空]({{< ref "/basics/go-short" >}})**，散户门槛高、工具有限）。

做多和「长期投资」不是同一个词：

| | 做多 | 长期投资 |
|--|------|----------|
| 强调什么 | **方向**：赌价格会涨 | **期限**：打算拿很久 |
| 时间 | 可短可长（几天、几周也算做多） | 通常以年计 |
| 关系 | 长期持有一只股，本质上也是在做多 | 长期持有 ≠ 一定是价值投资 |

## 和「做空」一句话对比

| | 做多 | 做空 |
|--|------|------|
| 操作顺序 | 先买 → 后卖 | 先借券卖出 → 后买回还券（简化为「先卖后买」） |
| 赚什么 | 涨了赚钱 | 跌了赚钱 |
| A 股散户 | ✅ 日常就是这样交易 | ⚠️ 门槛高，一般了解即可（见 [做空]({{< ref "/basics/go-short" >}})） |

## 常见误区

| 误区 | 正解 |
|------|------|
| ❌ 买入股票就叫「投资」，和做多无关 | 为赚价差而买涨卖出，就是做多；只是持有时间长短不同 |
| ❌ 做多一定赚钱 | 做多只是**方向押涨**，跌了就亏损 |
| ❌ 做多 = 加仓 | 做多是整体仓位方向；加仓是已有持仓后继续买 |
| ❌ A 股也能像期货一样随便做空 | 散户以做多为主，做空需融券等，规则更严、成本更高 |

## 什么时候有用 / 没用

| 适用场景 | 不适用场景 |
|----------|------------|
| 理解新闻里「多头」「看多」「做多」 | 把做多当成「稳赚」 |
| 和趋势跟踪、止损等策略一起理解仓位 | 在明显下跌趋势里死扛「因为我是做多」 |
| 区分「看涨」与「已经买好」的仓位状态 | 用做多去描述债券、外汇（口语相通，但规则不同） |
