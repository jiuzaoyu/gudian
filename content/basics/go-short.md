## 人话解释

**做空** = 你看跌，于是**先卖后买**（和做多相反）：

1. 先**借入**股票并**卖出**（此时手上没有这只股，是「欠」的）
2. 等股价下跌后，用更低的价格**买回**同样数量
3. **还券**给券商/出借方，赚取中间的价差（扣除利息、手续费等）

可以记成：**「空」= 空头 = 站在「跌」这一边**，赌价格往下走。

> 口语里说的「空仓」，有时指**没持股**；和「做空持仓」不是一回事，以具体语境为准。

## A 股里怎么做空？

普通散户日常「低买高卖」是**做多**。要做空，在 A 股主要靠 **融资融券** 里的 **融券卖出**（还有期货、期权等衍生品，门槛更高，此处不展开）：

| 步骤 | 说明 |
|------|------|
| 开通权限 | 需满足券商资产、交易经验等要求，签署融资融券协议 |
| 标的限制 | 只有交易所公布的**融券标的**才能借来卖，不是任意股票 |
| 借券卖出 | 向券商借入股票卖出，账户显示**融券负债** |
| 买券还券 | 股价下跌后买入相同数量还券，了结负债 |

若借不到券、标的被调出池子、或券商券源紧张，都可能无法顺利做空。

## 和「做多」一句话对比

| | 做多 | 做空 |
|--|------|------|
| 操作顺序 | 先买 → 后卖 | 先卖（借券）→ 后买（还券） |
| 赚什么 | 涨了赚钱 | 跌了赚钱 |
| 亏什么 | 跌了亏钱 | 涨了亏钱（股价理论上可以涨很多） |
| A 股散户 | ✅ 默认、最常用 | ⚠️ 门槛高、券源有限、成本更高 |

详见 [做多（买涨）]({{< ref "/basics/go-long" >}})。

## 做空的主要成本与风险

- **融券利息**：借股票要付费用，持股越久成本越高  
- **券源稀缺**：热门股可能借不到或费率很高  
- **上涨风险**：做空亏损在理论上**没有上限**（股价可以持续上涨），需严格止损  
- **逼空**：股价急涨时，空头集中回补买入，可能加剧上涨  
- **分红送股**：除权除息期间还券规则复杂，需按券商提示操作  

## 常见误区

| 误区 | 正解 |
|------|------|
| ❌ 「空仓」= 正在做空 | 空仓常指零持仓；做空是主动借券卖出的空头仓位 |
| ❌ A 股随便哪只股票都能做空 | 仅限融券标的，且需券商有券 |
| ❌ 做空一定比做多更赚钱 | 下跌行情才适合；借券成本、轧空风险都很大 |
| ❌ 做空 = 看空就不买 | 看空可以「不买」；做空是「先卖后买」的主动交易 |
| ❌ 和期货做空完全一样 | 规则、保证金、到期交割等不同，需单独学习 |

## 什么时候有用 / 没用

| 适用场景 | 不适用场景 |
|----------|------------|
| 理解新闻里「空头」「看空」「做空」 | 无融券权限、无券源时强行操作 |
| 对照做多，搞清交易方向 | 把做空当「稳赚」的跌市工具 |
| 评估对冲、套利等进阶话题前的入门 | 新手用高杠杆、高费率融券博短线 |
