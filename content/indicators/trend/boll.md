## 人话解释

**布林带**（Bollinger Bands，软件里常写 **BOLL**）是三条线围成的一条「**价格通道**」，由美国分析师 **John Bollinger（约翰·布林格）** 在 1980 年代提出。

它回答的问题不是「明天涨还是跌」，而是：**最近这段时间，股价通常在什么范围里波动？现在算不算偏贵或偏便宜？**

### 三条线分别是什么？

| 线 | 常见含义 | 默认怎么算（了解即可） |
|----|----------|------------------------|
| **中轨** | 价格的「中枢」 | 一般是 **20 日移动平均线（MA20）** |
| **上轨** | 通道上沿 | 中轨 + **2 倍标准差** |
| **下轨** | 通道下沿 | 中轨 − **2 倍标准差** |

标准差衡量「最近价格有多散、波动有多大」。所以：

- **通道变宽**：波动加大，市场更「躁」
- **通道变窄**：波动减小，市场在「憋着」（俗称 **收口**、**喇叭口收紧**）
- **收口之后**：有时会迎来方向选择（往哪边突破不保证，需结合其他信号）

可以把它想成股价的「**活动围栏**」——多数时候价格在围栏里晃，偶尔顶到或冲出上/下沿。

### 软件上常见怎么看？

- **靠近上轨**：在通道里位置偏高，有人当作 **偏强 / 可能超买** 参考（强势趋势里可以贴着上轨走很久）
- **靠近下轨**：位置偏低，有人当作 **偏弱 / 可能超卖** 参考
- **回到中轨附近**：震荡市里常被视为「回归中枢」
- **强势上涨**：股价可沿上轨运行；**弱势下跌**：可沿下轨运行——不等于「碰上轨必卖、碰下轨必买」

### 和均线、RSI、MACD 怎么区分？

| 指标 | 主要看什么 |
|------|------------|
| **布林带** | 波动范围 + 价格在通道里的相对位置 |
| **均线（MA）** | 过去一段时间的平均价，看趋势 |
| **RSI** | 近期涨跌力度，0～100 |
| **MACD** | 快慢线差，看趋势动能 |

布林带的中轨本身就是均线；常与 RSI、MACD、成交量等**配合**使用，不宜单独当买卖依据。

## 计算公式（了解即可）

默认参数多为 **20 日、2 倍标准差**（各软件可调）：

```
中轨 = N 日收盘价的移动平均（常见 N = 20）
标准差 = 这 N 日收盘价相对中轨的离散程度
上轨 = 中轨 + K × 标准差（常见 K = 2）
下轨 = 中轨 − K × 标准差
```

按正态分布经验，约 **95%** 左右的收盘价会落在 ±2 倍标准差范围内，所以通道会随波动**自动变宽变窄**，比固定百分比的通道更灵活。

## 常见误区

| 误区 | 正解 |
|------|------|
| ❌ 碰上轨必卖、碰下轨必买 | 强趋势可长时间沿轨道运行，触轨不等于立刻反转 |
| ❌ 收口一定马上大涨 | 收口只说明波动变小，突破方向需等待确认 |
| ❌ 布林带能预测未来 | 它是基于历史价格算的滞后指标，描述已发生的波动 |
| ❌ 通道越窄越安全 | 窄通道常意味「蓄势」，之后波动可能放大 |
| ❌ 单独用一个指标就够 | 宜结合趋势、量能、位置及其他指标综合看 |

## 什么时候有用 / 没用

| 适用场景 | 不适用场景 |
|----------|------------|
| 观察波动是放大还是缩小 | 代替基本面判断公司长期价值 |
| 看价格在通道里的相对高低 | 机械触轨抄底逃顶 |
| 辅助理解震荡与趋势的不同状态 | 追求精确到分钟的买卖点 |
